The account inventory advertises these fixed EasyApache container packages.

Redis 6.2

Available for account

Open cPanel Terminal or connect by SSH as this cPanel account, then run:

/usr/local/cpanel/scripts/ea-podman install ea-redis62

Valkey 7.2

Available for account

To use Valkey instead, run this fixed package command:

/usr/local/cpanel/scripts/ea-podman install ea-valkey72
  1. Run one package command in your account shell and wait for cPanel to finish setup.
  2. Return here and select Check again. ORM will verify the account-owned container and socket.
  3. Copy the socket connection example for your application after verification.

Administrator prerequisite: cPanel EA Podman needs AlmaLinux, Rocky Linux, or Ubuntu, EasyApache 4 container support, user namespaces, and a normal non-jailed account shell. ORM does not change host packages or kernel settings.
