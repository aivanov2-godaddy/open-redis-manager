# Public reference site notes

This directory keeps a page-by-page, paraphrased record of the public cPanel Redis Manager website used during ORM feature discovery. It describes what the site says; it does not verify the vendor's installed software or make those features ORM commitments.

The site displayed **v2.6.11** in the captures from 2026-11-21. Read the [REA evidence ledger](../rea-evidence.md) for capture IDs, coverage, and limits.

## Pages

- [Home](home.md): product positioning, audiences, integrations, pricing claim, FAQ topics, and navigation.
- [Documentation](documentation.md): public documentation sections and the functions it describes for cPanel and WHM.
- [Upgrade](upgrade.md): the public in-WHM update claims and post-update checklist.
- [Screenshot gallery](screenshots.md): all twelve source gallery surfaces, described without redistributing the vendor images.
- [Roadmap](roadmap.md): current release and the planned version families shown by the source.

## Comparing reference claims with ORM

The [feature catalog](../features/catalog.md) maps expected behavior to ORM's current implementation. Its implementation column links to repository code and evidence. The [ORM screenshot map](../features/screenshot-map.md) points to project-authored previews and captures.

The public pages are marketing and documentation content. They do not reveal server-side code, authenticated control-panel behavior, API contracts, or failure handling. Vendor commands, screenshots, logos, and copied page text are intentionally not included here.
