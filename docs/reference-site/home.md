# Reference site: home page

**Source:** [cpanelredismanager.com/index.php](https://cpanelredismanager.com/index.php)
**Observed:** 2026-11-21; the page displayed v2.6.11. See the [capture record](../rea-evidence.md#read-only-recheck-on-2026-11-21).

## Positioning and audiences

The page presents Redis and Valkey as cPanel/WHM-managed caching services. It frames the product around faster application responses, fewer repeated database queries, and control-panel management. Its audience sections address website owners, agencies and developers, and hosting providers or resellers.

## Advertised workflows and integrations

The home page points to these product areas:

- cPanel setup, service status, connection details, presets, monitoring, and account-level cache management.
- WHM fleet oversight, account operations, recovery, policy, package controls, and branding.
- Redis and Valkey support, with a claim that existing Redis accounts remain on Redis unless an administrator explicitly changes them.
- WordPress and WooCommerce object caching; Laravel cache, sessions, and queues; Magento; and custom PHP, API, membership, CRM, and dashboard workloads.
- Connection examples and guides for WordPress, Laravel, Magento, PHP, Node.js, Python, and LiteSpeed Cache are linked from the surrounding site content.

These are statements on the public page. Implementation and validation status for ORM are tracked separately in the [feature catalog](../features/catalog.md) and [integration matrix](../integrations.md).

## Gallery, release, and pricing claims

The page introduces three cPanel and nine WHM screenshot cards; the [gallery inventory](screenshots.md) lists them. It describes v2.6.11 as the current stable release and advertises **$4.95 per server per month**, including unlimited instances on the licensed server, updates, and support. This records the displayed price and package claim only; no purchase or license flow was exercised.

The FAQ topics cover Redis benefits, Valkey selection and migration, cPanel and WHM capabilities, licensing, application connectivity, production readiness, and reseller/white-label use. The home page links to separate documentation and upgrade pages.

See the [roadmap summary](roadmap.md) for the version plan shown by the site. Public roadmap and pricing content can change and is not ORM product policy.
