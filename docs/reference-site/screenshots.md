# Reference site: screenshot gallery

**Source:** [cpanelredismanager.com/index.php](https://cpanelredismanager.com/index.php), screenshots section.
The public gallery exposes three cPanel cards and nine WHM cards with accessible names and captions. The images and vendor logos are not copied into this repository.

| Area | Gallery card | Workflow described by its caption |
|---|---|---|
| cPanel | Dashboard overview | Service state, endpoint, AUTH controls, memory/database details, and lifecycle actions. |
| cPanel | Instance monitoring | Latency, memory, connections, uptime, command activity, and selectable trend range. |
| cPanel | Configuration and backups | Presets, instance settings, backup creation, and restore. |
| WHM | Server dashboard | Fleet counts, memory/connection totals, backend version, and historical charts. |
| WHM | Account management | Search/filter, per-account state and resource use, and quick actions. |
| WHM | CLI management | Select an account, run Redis CLI commands, and view output. |
| WHM | Backups | Per-account and server-wide backup actions. |
| WHM | Recovery | Maintenance scan and recovery actions for service/configuration issues. |
| WHM | Global defaults | Default cache settings and update controls. |
| WHM | Security controls | Firewall guidance, local binding visibility, and credential rotation controls. |
| WHM | Package configuration | Package-level availability and cache limits. |
| WHM | Branding controls | White-label name, logo, support link, colors, footer, and cPanel preview. |

The gallery also advertises a lightbox with previous, next, and close controls; an earlier read-only REA replay exercised these controls. The latest page-only recheck did not interact with the gallery. See the [REA evidence ledger](../rea-evidence.md) for both records.

ORM screenshots are original project assets and previews listed in the [ORM screenshot map](../features/screenshot-map.md). They use synthetic data unless their validation record explicitly says otherwise.
